# 成语画猜

独立双人成语画猜应用：150个成语、拼音和通俗释义。

画图者私下查看随机题目，收起答案后作画，对方猜测，最后一起揭晓。只提供随机抽题与换题，没有自选、搜索或题库浏览入口。支持3/6/12轮及画笔、橡皮、颜色、粗细、撤销和清空。

## 运行与部署

静态HTML/CSS/JavaScript，无构建步骤。GitHub Pages从本仓库main分支根目录发布。所有资源独立保存在本仓库，manifest限定本项目路径。

与出发吧和三词成故事使用独立仓库、目录和发布配置。不读取或写入其他项目数据，不使用Cookie、浏览器存储、Service Worker或共享后端。

网页不提供全词表入口；静态应用的题库仍属于客户端源码，不构成防开发者工具查看的保密机制。

画作仅在本轮页面内暂存，刷新即清空。无远程联机、自动判画或账户系统。
