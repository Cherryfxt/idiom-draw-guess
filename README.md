# 成语画猜

独立双人成语画猜应用：500个成语、拼音和通俗释义。

画图者私下查看随机题目，可以选择“画图”或“下一组”。画图后保留猜测、揭晓与交换角色的流程；下一组直接展示另一个随机成语，跳过不计入绘画轮数。没有自选、搜索或题库浏览入口。支持3/6/12轮及画笔、橡皮、颜色、粗细、撤销和清空。

每个成语一经展示就从本轮词库中移出，无论随后画图还是跳过。500个全部展示后重新洗牌，跨循环也避免紧接着出现相同成语。当前浏览器通过项目专属localStorage键保存剩余词序，刷新、结束或重新开始均不重置词库。清除浏览器数据、更换浏览器/设备会重新开始；浏览器禁止存储时只在当前页面内排重。

## 运行与部署

静态HTML/CSS/JavaScript，无构建步骤。GitHub Pages从本仓库main分支根目录发布。所有资源独立保存在本仓库，manifest限定本项目路径。

与出发吧和三词成故事使用独立仓库、目录和发布配置。不读取或写入其他项目数据；仅使用专属存储键 `idiom-draw-guess:shown-deck:v1`，不使用Cookie、Service Worker或共享后端。

网页不提供全词表入口；静态应用的题库仍属于客户端源码，不构成防开发者工具查看的保密机制。

画作仅在本轮页面内暂存，刷新即清空。无远程联机、自动判画或账户系统。
